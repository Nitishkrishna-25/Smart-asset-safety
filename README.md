# Smart Asset Safety & Data Logging System

STM32-based embedded product using FreeRTOS to monitor asset safety, detect faults, and log events in real time.

**Student:** Nitish Krishna M H
**Program:** B.E. Electronics and Communication Engineering, Sri Ramakrishna Engineering College, Coimbatore

## Overview
The system monitors temperature, current, and motion (accelerometer) on an asset, logs events with RTC timestamps to SPI flash, and sends GPS-tagged alerts over GSM. Under critical fault conditions it automatically disables the load.
